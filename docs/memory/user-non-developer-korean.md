사용자는 개발자가 아니다. 기술적 결정(스택·모델·저장소 등)은 "알아서 제일 좋은 걸로 판단해달라"고 위임했고, 설명은 전문 용어 없이 쉬운 한국어로 원한다.

**Why:** 계획을 보고 진행 여부를 결정하는 사람이라, 결과가 이해되어야 결정할 수 있다.
**How to apply:** 답변은 한국어 평이한 말로. 결정이 필요한 것만 짧게 묻고, 나머지는 합리적 기본값으로 진행한 뒤 무엇을 골랐는지 알린다. 계정 가입·API 키 발급은 사용자가 직접 해야 하므로 단계별로 안내한다(키는 채팅에 붙여넣지 않게 안내). 관련: [[core-finder-project]]
