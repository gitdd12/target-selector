# 브랜드 한 장 (초안, 2026-09-27)

랜딩·인터뷰 화면·결과지를 따로 고치다 보면 화면마다 느낌이 달라진다. 이 문서는 그 전에 정하는 공통 기준이다. 정해지면 세 화면 모두 이 기준을 따른다.

## 1. 한 문장 정체성

**세련된 검사지.** 감성 에세이도, 자기계발 콘텐츠도 아니고, 진지하게 측정하고 정확하게 보고하는 도구다.

- 근거: Ehrenberg-Bass 연구소의 distinctive assets 개념 — 브랜드는 화면 하나가 아니라, 여러 화면에서 반복되는 같은 신호(같은 색, 같은 글자 체계, 같은 톤)로 기억된다. 지금은 랜딩·인터뷰·결과지가 서로 다른 톤이라 이 반복이 없다.

## 2. 톤 — 이것이다 / 이것이 아니다

| 이것이다 | 이것이 아니다 |
|---|---|
| 담담하다, 정밀하다, 절제됐다 | 감성적이다, 다정하다, 응원한다 |
| 근거를 보여준다 | 확신을 준다 |
| 여백으로 무게를 준다 | 장식으로 채운다 |
| 필요한 곳에서만 움직인다 | 화면마다 움직인다 |

## 3. 글자

- 서체: Pretendard Variable 하나. 제목과 본문 모두. (2026-09-27 결정)
- 제목은 굵게(750선), 자간을 좁게(-0.04~-0.06em), 줄간격을 좁게(1.05~1.15) 쓴다 — 포스터 같은 무게감.
- 본문은 보통 굵기, 자간 기본, 줄간격 넉넉히(1.6~1.75) — 읽기 쉬움.
- 제목에 장식적 세리프나 손글씨체를 쓰지 않는다. 서체가 하나뿐이므로 **크기·굵기·자간·여백**으로만 위계를 만든다.

## 4. 색

- 기준(이미 결정, 2026-09-27): 흰 바탕(`#FFFFFF`) + 푸른 기 도는 검정(`#0D0C14`). 강조색을 따로 두지 않는다.
- 검정은 두 가지로만 쓴다: 글자, 또는 꽉 찬 배경(카드·버튼·섹션 전환). 회색은 옅은 것 하나(`#F6F6F5`, 카드 배경)만 쓴다.
- 결과지의 "일치도" 배지처럼 등급을 나타내는 곳에 한해 초록 계열을 최소한으로 쓴다(신뢰의 색, Labrecque & Milne 2012). 그 외 화면에는 색을 넣지 않는다.

## 5. 여백과 레이아웃

- 화면(특히 첫 화면)은 **요소 하나가 화면의 목적을 다 말하게** 만든다. 제목·부연·버튼·그림을 한 화면에 같이 두지 않는다.
  - 근거: 시각적 복잡도가 낮을수록, 그 분야다운 전형적인 모양일수록 첫인상 평가가 좋다(Tuch 외 2012). 첫인상은 0.05초 안에 정해지고 그 판단이 유지된다(Lindgaard 외 2006).
- 카드·상자·구분선은 **정보를 분리해야 할 때만** 쓴다. 설명이 필요 없는 화면에 상자를 두르지 않는다.
- 한 화면 안에서 위계는 최대 2단계(예: 제목 + 캡션)로 제한한다. 3단계 이상(제목+부연+상자+목록)은 문서처럼 보인다.

## 6. 움직임

- 스크롤 자체를 가로채거나 속도를 바꾸지 않는다(스크롤재킹 금지). 스크롤은 사용자 것이고, 화면은 스크롤 위치에 따라 바뀌기만 한다.
  - 근거: NN/g, scrolljacking은 통제감을 해쳐 사용성을 떨어뜨린다.
- 움직임은 **문장이 말하는 변화를 그대로 보여줄 때만** 넣는다(시대가 바뀐다 → 사진이 바뀐다, 코어 하나가 두 직업이 된다 → 선이 갈라진다). 뜻 없는 장식 움직임(둥실거림, 반짝임)은 쓰지 않는다.
- `prefers-reduced-motion`을 켠 사람에게는 움직임 없이 완성된 화면을 그대로 보여준다(WCAG 2.3.3).
- 정적인 화면(설명이 필요 없는 선언 하나)에는 움직임을 넣지 않는다. 모든 섹션에 움직임을 넣는 것은 목표가 아니다.

## 7. 쓰지 않는 것 (기존 1단계 문서 재확인)

파스텔·베이지, 손그림, 밤하늘·별자리, 웃는 인물 사진, "진짜 나를 찾으세요" 류의 약속형 문장, 세 원이 겹치는 배경 장식(이키가이 그림과 같아 보임), 과장된 확신("정확한", "완벽한").

## 8. 적용 범위와 순서

이 기준은 랜딩부터 적용하고, 랜딩이 확정되면 인터뷰 화면(채팅 UI) → 결과지 순서로 같은 톤에 맞춘다. 지금 인터뷰 화면은 메신저 말풍선 모양이라 "세련된 검사지"보다 "친구와의 채팅"에 가깝다. 이 불일치는 랜딩이 아니라 인터뷰 화면 쪽을 고쳐서 없앤다.
