# 점수 시스템 — 코어와 직업 연결

## 본질 유사도

- O\*NET 916개 직업마다 업무 목록을 먼저 읽고, 그걸 바탕으로 그 직업의 **본질 문장**을 만든다. 통념이 아니라 실제 업무가 근거다.
- 사람의 코어 문장과 직업 본질 문장을 직접 비교해 점수를 준다.
- 점수 구간은 기준 예시(앵커)로 고정해서, 판정이 흔들리지 않게 했다.

| 구간 | 의미 | 앵커 예시 |
|---|---|---|
| 90~95 | 직업 이름을 빼면 코어와 거의 같은 말 | "가르치고 성장을 돕는다" × 초등교사 = 92 |
| 70~88 | 코어가 그 일의 주된 방식 | |
| 45~65 | 일부만 맞음, 방향이 반대, 여러 수단 중 하나 | "이야기 전달" × 초등교사 = 55 / "패턴으로 미래 예측" × 형사 = 45 |
| 30~45 | 기법은 겹쳐도 지향이 정반대 | |
| 20~35, 5~15 | 흔적이 약함, 거의 없음 | "손으로 만지며 체득" × 건축가 = 30 |

## 핵심 구분: 대표 동사인가, 기법 하나인가

같은 초등교사라도 코어가 그 직업의 **대표 동사**(가르친다)를 가리키면 92, 그 밑의 **기법 하나**(이야기 전달)를 가리키면 55다.

이 구분은 앵커 예시를 고르다 나왔다. 처음엔 교사의 90점대 예시로 "상황에 맞게 접근을 바꾼다"를 썼는데, "교사의 핵심은 적응이 아니라 가르치기 아니야?"라는 의문이 들었다. 맞는 지적이었고, 이후 전체 구간 체계의 기준이 됐다.

건축가 예시도 마찬가지다. "건축가는 손으로 짓는다"는 통념과 달리, 실제 업무 근거로 만든 본질은 점검과 조율이라 30점이다. 통념이 아니라 데이터로 판단한다.

## 결과 목록

- 45점 이상만 올린다.
- "확인된 대상"과 "아직 확인 안 된 대상" 두 목록으로 나눠 각 5개씩 보여준다.

## 가치관 축

- O\*NET의 Work Styles·Work Context 공식 데이터를 그대로 썼다. 새 분류를 만들지 않았다.
- 코어 구간은 실제 사례 63건으로 반복 검증했지만, 가치관은 그런 검증을 거치지 않았다. 그래서 **명백히 충돌할 때만 한 구간 내리고, 애매하면 아무것도 하지 않는다.** 검증 안 된 것을 검증된 것처럼 정교하게 쓰지 않기 위해서다.
